## Why Tabs?

Switching between related Markdown files (a README and its CHANGELOG, for
example) without leaving the terminal keeps you focused. The query you type
is shared across every open tab, so you can compare how the same query
behaves across multiple documents.

> Press `Tab` / `Shift+Tab` or `←` / `→` to switch tabs.
